HGT Actor-Critic Architecture Flow

A compact PPT-ready diagram of the current implementation: typed graph input, type-specific projection, 3-layer HGTConv encoder, and actor-critic outputs.

Input Operation, vehicle, and zone nodes keep different raw feature sizes before projection.
Encoder Each node type is projected to 128 dimensions, then processed by 3 HGTConv layers.
Q/K/V HGTConv uses type-specific linear projection: 128 -> 384 -> K/Q/V.
Output Actor scores all operations then masks infeasible ones; critic pools unscheduled operations.
